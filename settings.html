API presets
Custom APIs use the currently selected Dialogue Completion generation preset. API keys are stored by the SillyTavern server.
Default: 10 layers, equivalent to about 5 user/AI exchanges. Automatic generation can incur API charges.
Chat context range Both modes keep the newest content and stop at the input token budget. System messages do not count toward X but are retained when they fall inside the selected range.
Storage Summaries and aliases are stored in this browser's IndexedDB by default. Chat JSONL files are not modified. Embedded data follows exports and backups, but saving rewrites the chat JSONL. Enabling this does not rewrite old chats automatically.
